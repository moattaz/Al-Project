# 🧠 Checkers AI Game

A simple Checkers (Draughts) game built using Python with an AI opponent.
The AI uses basic decision-making algorithms to simulate intelligent gameplay.

---

## 🎮 Features

* Play Checkers against AI
* Basic AI using Minimax algorithm
* Simple and clean GUI
* Turn-based gameplay

---

## 🛠️ Technologies Used

* Python 3
* Pygame

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/checkers-ai.git
cd checkers-ai
```

### 2. Create virtual environment

```bash
python -m venv venv
```

### 3. Activate virtual environment

**Windows (PowerShell):**

```bash
venv\Scripts\Activate.ps1
```

**Windows (CMD):**

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install pygame
```

### 5. Run the game

```bash
python main.py
```

---

## 🧠 How the AI Works

The AI is based on the **Minimax algorithm**, which evaluates possible moves and chooses the best one by simulating future game states.
